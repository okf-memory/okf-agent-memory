# OKF Agent Memory v0.1.2 — Trust Ordering & Stale Gating

> **OKF Agent Memory v0.1.2** reinforces validator trust ordering, introduces the opt-in `--stale` gate for CI pipelines, hardens legacy checks, and corrects security advisory contact domains.

---

### Key Fixes & Improvements

#### 1. Validator Trust Ordering Enforcement
* **Chronological Integrity**: Enforced that human verification timestamps (`verified.at`) cannot chronologically precede agent generation timestamps (`generated.at`), preventing self-authorization loops or forged timestamps.

#### 2. Opt-in Stale Gating (`--stale`)
* **CI Freshness Guardrail**: Added the `--stale` flag to `okf validate`. When enabled, validation fails if concepts exceed project-defined staleness thresholds, encouraging continuous knowledge updates during PR reviews.

#### 3. Security Advisory Email Alignment
* **Contact Domain**: Corrected the security advisory email address domain in project documentation to match the official project domain.
