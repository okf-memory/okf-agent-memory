# OKF Agent Memory v0.1.1 — Dual-Mode & MCP Protocol Conformance

> **OKF Agent Memory v0.1.1** resolves MCP server JSON-RPC 2.0 notification compliance, adds dynamic multi-bundle resolution, establishes automated Homebrew formula templating, and documents Dual-Mode (MCP-First) agent workflows.

---

### Key Fixes & Improvements

#### 1. MCP Server JSON-RPC 2.0 Compliance
* **Notification Handling**: Ensured JSON-RPC notifications (requests without an `id` field, such as `notifications/initialized`) do not generate invalid null responses or terminate the stdio session, strictly complying with the JSON-RPC 2.0 and MCP specifications.
* **Stream Resilience**: Hardened stdio reader and writer handling against malformed packets.

#### 2. Dynamic Multi-Bundle Resolution
* **Multi-Corpus Support**: Extended the MCP server to support dynamic bundle resolution via tool arguments (e.g. `okf_search(bundle="examples/software")`), enabling agents to query multiple independent OKF bundles in a single session.

#### 3. Dual-Mode (MCP-First) Agent Workflows
* **Agent Integration Guides**: Updated agent instructions and skills to document dual-mode operation: prioritizing in-process MCP tools when available and falling back to the standalone CLI for shell/CI workflows.

#### 4. Automated Homebrew Formula Templating
* **Release Pipeline**: Automated `Formula/okf.rb` generation and tap synchronization in the GitHub Actions release workflow.

---
